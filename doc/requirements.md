# Fracture Portrait 需求文档

## 1. Overview

一款 8–15 秒的全屏视觉玩具：玩家轻触自己的头像，裂纹从触点瞬间穿过
肖像，停留 1.35 秒后自动复原，回到可再次触发的完整状态。

## 2. Visual Design

画面主体占满 100% 视口，默认内容为玩家头像；顶部使用超大衬线标题，
底部只保留极轻的身份标签。原作的 12 扇区裂纹、噪声网格裂缝、中央放射裂缝
和玻璃位移是唯一主视觉，不添加飞散碎片、发光粒子或卡片式 UI。详细系统见
`doc/visual.md`。

## 3. Game Mechanics

- 完整态持续等待输入；首次进入 850 毫秒后播放一次幽灵手指演示。
- 轻触时记录归一化触点，并为本轮生成 0–1 的随机裂纹种子。
- 破裂阶段 180 毫秒内把位移强度从 0 推至 0.052。
- 保持阶段持续 1,350 毫秒，裂纹和位移保持可观察。
- 复原阶段持续 900 毫秒，把位移和裂纹透明度平滑降至 0。
- 复原完成后回到完整态；重复点击会从新触点重新开始一轮。
- WebGL DPR 上限为 2；页面不可见时停止绘制，恢复可见后继续。
- `?baseline=1` 使用原作照片、原作参数和原作点击行为，不显示产品 UI。

## 4. Controls

- Pointer / Touch：单指轻触任意肖像位置，裂纹以该位置为中心生成。
- Keyboard：按 Enter 或 Space 在画面中心触发一次破裂。
- 触控画布使用 `touch-action: none`，输入通过单一 `pointerdown` 监听。
- 不设置依赖文字的单指说明；幽灵手指的移动与真实裂纹效果同步。

## 5. Win / Lose Conditions

本作没有胜负和计分。每一轮的闭环是“完整肖像 → 破裂 → 停留 → 自动复原”；
复原即完成一次体验，不需要刷新或进入结算页。

## 6. Sound Effects

- 首次用户触发后才创建 AudioContext。
- 破裂：95–1,900 Hz 的 55 毫秒带通噪声，快速衰减，音量上限 0.12。
- 复原：330–165 Hz 的 260 毫秒正弦滑音，音量上限 0.035。
- 自动演示静音；系统静音或音频初始化失败时不影响视觉。
